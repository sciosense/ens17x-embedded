# ScioSense ENS17x C Library

C library for the ENS17x digital four channel MOX gas sensors with I2C interface from ScioSense.

ENS17x is a range of digital multi-gas metal oxide (MOX) sensors, specifically designed for automotive-grade air quality monitoring. It offers raw resistance outputs from three independent MOX hot plates, each with different sensitivities to various gases.
